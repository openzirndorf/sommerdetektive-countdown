# Downloads

Hier die fertigen Werbematerialien ablegen — die Startseite verlinkt genau
diese Dateinamen:

| Datei                     | Inhalt                          |
| ------------------------- | ------------------------------- |
| `sharepic.png`            | Sharepic für Instagram (PNG, ideal 1080×1080 oder 1080×1350) |
| `flyer.pdf`               | Flyer zum Ausdrucken            |
| `poster.pdf`              | Poster zum Aushängen            |

Solange eine Datei fehlt, führt der jeweilige Download-Link auf der Seite
ins Leere (404) — also am besten vor dem Veröffentlichen alle drei ablegen.
